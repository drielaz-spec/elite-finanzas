# Banco de estilos

Referencias de estilo para los próximos vídeos. Cada carpeta tiene:

- `referencia.mp4`: el vídeo original (solo para consulta interna, no se publica).
- `hoja-de-contactos.png` y `fotogramas/`: los momentos clave.
- `transcripcion.json`: lo que se dice, con tiempos (Whisper large-v3).
- `ESTILO.md`: la ficha del estilo (estructura del guion, tipografías, colores, posiciones, ritmo).
- `plantilla/`: proyecto de Hyperframes con el estilo ya montado, listo para copiar.

| Estilo | Para qué sirve | Carpeta |
|---|---|---|
| Diario 30 días | Historias de resultado contadas día a día, con pruebas (capturas, cifras) | `diario-30-dias/` |
